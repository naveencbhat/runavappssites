About

BharatBolo keeps private content end-to-end encrypted on users' devices: the server only routes ciphertext. The E2EE core passes a 21-test suite (tamper & replay rejection, multi-device fan-out, device revocation, safety numbers), and the API adds 50 unit tests and 15 e2e tests covering OTP, encrypted-at-rest PII, refresh-token replay and admin RBAC.
