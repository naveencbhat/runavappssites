About

Dockerised services pair a Node API + BullMQ workers with Python FastAPI inference (Qwen3 via vLLM, IndicTrans2, embeddings, quality checks and self-correction), LoRA fine-tuning, and Prometheus/Grafana monitoring. languages.json is the single source of truth for the 14 supported languages, and mock models keep development fast on machines without GPUs.
